### 🚀 Para Começar

#### 1. Compilação (OK ✅)
```bash
cd c:\Reps\DockAI
dotnet build
# ✅ Sem erros!
```

#### 2. Setup da UI
```bash
cd src\AgentDock.UI
npm install
npm run build
```

#### 3. Rodar o App

**Opção A: Desktop (Recomendado)**
- Abra `AgentDock.sln` no Visual Studio
- Aperte F5
- ✅ Pronto!

**Opção B: Desenvolvimento**
```bash
# Terminal 1
cd src\AgentDock.Backend
dotnet watch run

# Terminal 2
cd src\AgentDock.UI
npm run dev

# Abra http://localhost:5173
```
