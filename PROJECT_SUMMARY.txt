❓ TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════════════

  Problem: "Port 5000 in use"
  → netstat -ano | findstr :5000
    taskkill /PID <PID> /F
  
  Problem: "npm packages missing"
  → cd src/AgentDock.UI && npm install
  
  Problem: "WebView2 error"
  → Install WebView2 Runtime (Windows 10)
    https://bit.ly/webview2
  
  Problem: ".NET version mismatch"
  → dotnet --version (should be 8.0+)
  
  See README.md for more troubleshooting!
