# Contributing to AgentDock

Thank you for your interest in contributing to AgentDock! 🎉

## 🚀 Quick Start

1. Fork the repository
2. Clone your fork: `git clone https://github.com/YOUR_USERNAME/AgentDock.git`
3. Run setup: `.\setup.ps1` (Windows) or `./setup.sh` (Unix)
4. Create a branch: `git checkout -b feature/amazing-feature`
5. Make your changes
6. Test thoroughly
7. Commit: `git commit -m "Add amazing feature"`
8. Push: `git push origin feature/amazing-feature`
9. Open a Pull Request

## 📋 Development Guidelines

### Code Style

- **C# (.NET)**: Follow Microsoft's C# coding conventions
- **TypeScript/React**: Use ESLint and Prettier configurations
- **Commit Messages**: Use conventional commits (feat:, fix:, docs:, etc.)

### Testing

- Test your changes on multiple platforms when possible
- Ensure the app builds successfully: `npm run build`
- Test with different GPU types (CPU, CUDA, ROCm, etc.) if applicable

### Pull Request Process

1. Update README.md if you add/change features
2. Update documentation in `/docs` if needed
3. Ensure all tests pass
4. Request review from maintainers
5. Address any feedback promptly

## 🐛 Reporting Bugs

Use GitHub Issues with the bug report template:
- Clear description of the issue
- Steps to reproduce
- Expected vs actual behavior
- System information (OS, GPU, .NET version)
- Screenshots if applicable

## 💡 Suggesting Features

Use GitHub Issues with the feature request template:
- Clear description of the feature
- Use cases and benefits
- Possible implementation approach

Be respectful, inclusive, and constructive in all interactions.

Open a GitHub Discussion or reach out to the maintainers.
